# arys-ashutosh-kumar-footpeg-fea
Structural design and finite element analysis of a motorcycle rearset footpeg bracket under vertical and lateral loading conditions, including safety factor and fatigue evaluation.
Structural Bracket (Rearset Footpeg) + Fatigue FEA

Project Overview

This project focuses on the design, modeling, and finite element analysis (FEA) of a motorcycle rearset footpeg assembly using SolidWorks Premium 2021 and SolidWorks Simulation. The objective was to evaluate the structural integrity and fatigue performance of the assembly under realistic rider loading conditions.

Assignment Objective

- Design a motorcycle rearset footpeg assembly.
- Perform static structural analysis under:
  - 1.8 kN vertical load
  - 0.5 kN lateral load
- Evaluate factor of safety and deformation.
- Predict fatigue performance for 500,000 load cycles.
- Propose engineering design improvements.

Software Used

- SolidWorks Premium 2021
- SolidWorks Simulation 2021
- GitHub
- Microsoft Word

Material

Aluminium 6061-T6

Analysis Performed

Static Structural Analysis

The assembly was analyzed under combined vertical and lateral loading conditions to determine:

- Von Mises Stress
- Resultant Displacement
- Equivalent Strain
- Factor of Safety (FOS)

Fatigue Analysis

A constant amplitude fatigue study was conducted using a manually defined S-N curve for Aluminium 6061-T6 under fully reversed loading (R = -1) for 500,000 cycles.

Key Results

Parameter| Result
Maximum Von Mises Stress| 119 MPa
Maximum Displacement| 0.3505 mm
Maximum Equivalent Strain| 9.23 × 10⁻⁴
Minimum Factor of Safety| 2.3
Predicted Fatigue Life| > 1,000,000 Cycles
Fatigue Damage| 0%

Design Improvements

1. Increase fillet radius at critical stress concentration zones to reduce peak stress.
2. Optimize mounting bracket wall thickness to reduce weight while maintaining structural safety.
